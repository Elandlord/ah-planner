# Eigen receptfoto's

Zet hier je eigen foto's neer, bijvoorbeeld `gnocchi-bake-aubergine.jpg`.
De bestandsnaam is het recept-id uit `data/recipes.ts`.

De app pakt automatisch `/recipe-images/<recept-id>.jpg` als die bestaat, anders
de productfoto van het eerste ingredient.

Alles in deze map behalve dit bestand blijft buiten git: foto's uit kookboeken
mag je thuis gebruiken, maar niet publiceren in een openbare repository.
